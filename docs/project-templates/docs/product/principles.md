# Product Principles

Product behavior principles for this project.

Use this file to help the agent understand what kind of product is being built and which trade-offs should be preserved. These principles should shape implementation choices, not sit as slogans.

## Principles

Add stable product principles below. Keep each principle concrete enough that it can guide a decision.

Describe the principle.

## Questions to Answer

If the principles are not clear yet, use these questions to draft them:

- Who is this product for?
- What should users be able to trust?
- What should the product never do, even if it would be easier?
- What kind of simplicity matters here?
- What kind of failure is more costly than others?
- What trade-offs should the agent preserve during implementation?
