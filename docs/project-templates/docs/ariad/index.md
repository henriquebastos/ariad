- `docs/project/briefing/index.md`

Use the Driver/Navigator roles, route work through Exploration, Delivery, or Refinement, preserve Process/Project/Product coherence, validate observable behavior, update the smallest authoritative documentation surface, and follow local checkpoint and history policy.
