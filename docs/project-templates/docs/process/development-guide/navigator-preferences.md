# Navigator Preferences

Ariad ships with opinionated defaults. Replace these when the project or Navigator has a better explicit local answer.

- **Commit policy:** commit after a coherent story or meaningful change is validated and accepted.
- **Push policy:** ask before pushing to a shared remote.
- **Checkpoint compression:** use full checkpoints for non-trivial work and compress only trivial, low-risk changes.
- **Documentation detail:** make the smallest update that keeps the project coherent.
- **Worklog policy:** record meaningful milestones as one file per entry, not every edit.
- **Branch and pull request habits:** describe local branch, review, and merge expectations.

Keep preferences current rather than accumulating historical alternatives. If changing a preference has consequential rationale, preserve that rationale in a decision record.
