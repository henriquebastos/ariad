# Method

Ariad is an operating system for human-agent software work.

It is not a prompt collection. It is not a documentation template by itself. It is a method that tells an agent how to participate in a project without dissolving the project's memory, standards, and product intention.

The method has five core pieces:

- explicit human-agent roles,
- a triad for keeping process, project, and product connected,
- a story lifecycle for bounded delivery,
- mandatory checkpoints that prevent silent drift,
- living documentation that lets the repository remember itself.
