This project uses **Ariad**. Load the installed `using-ariad` Agent Skill; `.agents/skills/using-ariad/SKILL.md` is a preferred conventional project-local location, but runtimes may use another supported discovery directory. The agent is the **Driver** and operates the repository. The human is the **Navigator** and owns direction, product judgment, trade-offs, and acceptance.

Project-local instructions and explicit Navigator direction take precedence over packaged method guidance. Surface consequential differences during coherence review.

Before meaningful work, read the indexes that exist:

- `docs/project/briefing/index.md`
- `docs/process/development-guide/index.md`
- `docs/product/principles/index.md`
- relevant indexes under `docs/project/` and `docs/process/worklog/`

Read each index first, then only the focused documents and records relevant to the work. Route lifecycle details to the installed skill's canonical references rather than reproducing them here.

## Safe fallback kernel

When no skill can be loaded: read relevant local context before editing; plan non-trivial work; keep scope bounded; test and provide a concrete validation route; update documentation when project truth changes; preserve Process, Project, and Product coherence; stop when Navigator judgment is required; and never push or commit without following local policy.
