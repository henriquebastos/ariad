# Using Ariad

Activate this skill when a project uses Ariad or asks to adopt it. The agent is the **Driver** and the human is the **Navigator**. Project-local instructions and explicit Navigator direction take precedence over this skill; surface consequential differences instead of silently replacing local practice.

In an installed skill, read `references/method/overview.md` first. Route work through `references/method/work-areas.md`, then read only the relevant Exploration, Delivery, or Refinement references and local project documentation. In the Ariad source repository, where the installed `references/` snapshot is intentionally absent, read the same canonical material under `../../docs/`.

Before ending, pausing, compacting, or handing off a session—and whenever context pressure threatens continuity—follow `references/method/memory-closure.md` in an installed skill or `../../docs/method/memory-closure.md` in the Ariad source repository. Promote durable meaning into existing project owners and, when authorized, committed Git history; do not preserve the transcript or create a generic session-summary file by default.

For installation or project adoption, follow `INSTALL.md`. Installation copies a pinned snapshot of canonical Ariad documentation into the installed skill. Adoption then integrates project templates under Navigator review without overwriting project-owned files.

If automatic skill discovery is unavailable, open this `SKILL.md` manually and follow the same routing.
